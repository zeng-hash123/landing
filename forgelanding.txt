DESIGN DIRECTION
- Modern SaaS aesthetic — clean, confident, not overly playful (this is a tool 
  being sold to professional agencies, not consumers)
- Primary accent color: a strong, trustworthy blue or indigo (open to a bold 
  alternative like a deep orange if you want more energy — pick one and use 
  it consistently)
- Generous whitespace, clear visual hierarchy, no more than 2 fonts 
  (one for headings, one for body — use next/font-equivalent via Google 
  Fonts import or self-hosted fonts for performance)
- Avoid generic AI-SaaS clichés (purple-blue gradient blobs, floating 3D shapes) 
  — aim for something that feels more grounded and professional, fitting an 
  agency-facing tool rather than a consumer AI toy
- Mobile-first responsive throughout

PERFORMANCE

  interactivity (e.g. a mobile nav toggle can use Astro's client:load or 
  even plain CSS-only toggle via checkbox hack to avoid JS entirely)
- Optimize all images via Astro's <Image /> component with proper width/height 
  to avoid layout shift
